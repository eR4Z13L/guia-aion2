# Guia Aion 2 (site local)

Abra `index.html` com duplo clique. Não precisa de internet nem de servidor, mas as fontes bonitas vêm do Google Fonts (sem internet usa a fonte do sistema).

- **Guias das classes**: menu no topo, clique na classe e escolha PvE ou PvP.
- **Guia geral, Mapa, Dicas, Ferramentas**: páginas gerais, no menu.
- O progresso (nível, Gear Score, Daevanion) fica salvo **só no seu navegador**.

## Mandar para amigos pelo GitHub
1. Coloque esta pasta num repositório. Os amigos clicam em **Code > Download ZIP**, extraem e abrem `index.html`.
2. Opcional: ative o GitHub Pages (Settings > Pages) e o site abre por um link, sem baixar.

Dados do mapa: allthings.how e AION2 Hub. Arte do mapa © NCSOFT.
Para refazer o site depois de mudar os guias: `python -X utf8 guia/montar.py hub` e `python -X utf8 guia/montar_site.py`.
